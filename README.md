# WY Code Studio

เว็บ HTML สำหรับ GitHub Pages: นำเข้า Excel → เลือก CODE → ตั้งวันหมดอายุ / Lot / ขายหรือแจก → ดาวน์โหลด CSV

## เปิดใช้งาน

เปิด `index.html` ในเบราว์เซอร์ได้ทันที ต้องเก็บ `styles.css`, `app.js`, `core.js` และโฟลเดอร์ `vendor` ไว้ด้วยกัน

## นำขึ้น GitHub Pages

1. สร้าง repository แล้วอัปโหลดไฟล์เว็บทั้งหมด รวมโฟลเดอร์ `vendor` และ `.nojekyll` (ไม่ต้องอัปโหลด Excel ต้นฉบับ)
2. ใน repository เปิด Settings → Pages
3. เลือก Deploy from a branch แล้วเลือก branch `main` และโฟลเดอร์ `/ (root)` กด Save
4. รอ GitHub เผยแพร่ แล้วเปิด URL ที่แสดงในหน้า Pages

## ข้อมูลที่ส่งออก

ไฟล์ที่ดาวน์โหลดใช้ชื่อ `Code.csv` ทุกครั้ง

วันหมดอายุเริ่มต้นเป็นวันที่ 31 ธันวาคมของปี ค.ศ. ปัจจุบันตามเครื่องผู้ใช้ และสามารถแก้ไขวันที่ได้

ลำดับคอลัมน์: `CODE,EXP,Lot,ใช้สำหรับ` โดย EXP เป็น `DD/MM/YYYY` ปี ค.ศ. และใช้สำหรับเป็น `ขาย` หรือ `แจก` ทุกแถว เลือกเฉพาะ No. Lot (1–9999) ระบบสร้างชื่อจากปีปัจจุบันของเครื่อง เช่น ปี 2026 เลือก 7 ได้ `WY26 LOT.07`

- CSV ใช้ comma, CRLF และ UTF-8 BOM รองรับภาษาไทย มีการ escape เครื่องหมาย quote และ comma
- รองรับ `.xlsx`, `.xls` รวม HTML table ที่บันทึกเป็น `.xls` แบบไฟล์ตัวอย่าง
- ตัดช่องว่างรอบ CODE และ apostrophe ตัวแรกที่ Excel ใช้กำกับข้อความ รักษาศูนย์นำหน้าจากข้อความ/รูปแบบเซลล์
- ข้ามช่อง CODE ว่าง เก็บ CODE ซ้ำตามต้นฉบับ เว้นแต่เลือกตัดซ้ำ
- ค้นหาหัวคอลัมน์ CODE และแถวหัวตารางอัตโนมัติ โดยใช้ชีตแรกที่พบ CODE หากไม่พบจะแจ้งให้แก้ไขไฟล์ พรีวิวสูงสุด 100 แถว แต่ส่งออกครบทุกแถว
- จำกัดไฟล์ 20 MB ไม่มี backend และไม่ส่งข้อมูล Excel ออกไปนอกเครื่อง
- ค่าเริ่มต้นสำหรับ BarTender ส่งออก CODE เดิม เช่น `015248` โดยไม่มีสูตร ให้ใช้ Code.csv ที่ดาวน์โหลดโดยตรง ไม่เปิดและบันทึกทับผ่าน Excel
- โหมด “โหมดสำหรับเปิดใน Excel เท่านั้น” ปิดเป็นค่าเริ่มต้น หากเลือกจะส่งออก CODE ที่เป็นตัวเลขล้วนเป็นสูตรข้อความ เช่น `="016781"` เพื่อให้ Excel แสดงศูนย์นำหน้าและไม่ปัดเลขยาว ส่วนตัวอย่างบนเว็บแสดง CODE เดิม ไม่ควรใช้โหมดนี้กับ BarTender
- เมื่อนำ CSV เข้าระบบอื่น ให้ปิดโหมดนี้เพื่อส่งออก CODE เดิมโดยไม่มีสูตร หากเปิดไฟล์โหมดปกติใน Excel ให้ใช้ Data → From Text/CSV และกำหนด CODE เป็น Text เพื่อรักษาศูนย์นำหน้า
- ใช้สูตรข้อความเฉพาะ CODE ที่มีแต่เลข 0–9 ข้อมูลอื่นส่งออกตามต้นฉบับ ควรใช้ไฟล์จากแหล่งที่เชื่อถือได้เมื่อเปิด CSV ในโปรแกรมตารางคำนวณ

ตัวอ่านไฟล์: SheetJS CE 0.20.3 เก็บใน `vendor/xlsx.full.min.js` จาก [แหล่งทางการ](https://docs.sheetjs.com/docs/getting-started/installation/standalone/) ใช้ Apache-2.0


## ติดตั้งบนมือถือ

อัปโหลดไฟล์เว็บทั้งหมด รวม `manifest.webmanifest`, `pwa.js`, `sw.js` และโฟลเดอร์ `icons` ขึ้น GitHub Pages แล้วเปิด URL แบบ HTTPS

- Android: เปิดด้วย Chrome แล้วกด “ติดตั้งแอป” ในเว็บเมื่อปุ่มปรากฏ หรือเลือกจากเมนูเบราว์เซอร์
- iPhone / iPad: เปิดด้วย Safari → แชร์ → เพิ่มไปยังหน้าจอโฮม
- หลังเปิดเว็บออนไลน์และโหลดข้อมูลแอปครบแล้ว สามารถเปิดใช้งานออฟไลน์ได้ ไฟล์ Excel ที่เลือกจะไม่ถูกเก็บในแคช และต้องเลือกไฟล์ใหม่เมื่อเปิดแอปใหม่
- หากแก้ไขรายการไฟล์แอปในอนาคต ให้เพิ่มเลขเวอร์ชัน CACHE ใน `sw.js` ด้วย

ทดสอบ manifest, ขนาดไอคอน, service worker, เส้นทางย่อยแบบ GitHub Pages และนำเข้า Excel ขณะออฟไลน์ผ่านเบราว์เซอร์แล้ว การแสดงปุ่มติดตั้งขึ้นอยู่กับเบราว์เซอร์และสถานะการติดตั้งของผู้ใช้
